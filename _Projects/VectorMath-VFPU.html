Project Description

Sony made a math library for the PS3 called VectorMath, and I'm porting it to the PSP (PlayStation Portable) with VFPU support.

The VFPU (Vector Floating Point Unit) is a coprocessor on the PSP which does SIMD (Single Instruction, Multiple Data) instructions. This allows for faster vector and matrix math which is important for high-performance games.

The VFPU version is currently about 3.5x faster than the scalar version.
